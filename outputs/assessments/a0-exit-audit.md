# A0 Level Check: Item Audit

This is an end-of-level progress check, not the full CEFR placement exam. Each
student question should test one main target, use adult contexts, and have one
unambiguous answer. Easy anchor items are appropriate at A0, but an item should
not be easy only because the distractors are nonsense.

## Student Questions

1. **The verb be — keep.** A focused `I + am` anchor. The two distractors
   represent the exact agreement errors taught in the A0 lesson.
2. **Subject pronouns — keep.** The student must change Marta's first-person
   statement into a third-person introduction. This tests viewpoint, not only
   recognition of `she`.
3. **Articles — keep.** The profile establishes the job, so the question tests
   only the missing or incorrect article before `nurse`.
4. **Demonstratives — keep.** All three choices are grammatical. Only
   `these` matches two objects held near the speaker.
5. **Regular plurals — keep.** The context establishes a quantity of two, and
   the distractors represent missing plural `-s` and an unnecessary article.
6. **Possessive adjectives — keep.** All choices are grammatical; the student
   must follow who is speaking to choose `my`.
7. **Question words — keep.** One distractor is a common transfer error and one
   is a valid question with the wrong meaning.
8. **Profile reading — keep.** Every choice is grammatical. The student must
   check both country and job instead of selecting the only well-formed option.
9. **Booking reading — keep.** The choices differ by one detail at a time and
   test day, time, and location.
10. **Greeting — keep as an easy anchor.** It checks whether the student can
    distinguish the opening of an interaction from a later response or a
    farewell.
11. **Spelling listening — keep.** Audio removes the old visual-copy shortcut.
    The alternatives test a missing repeated letter and a similar initial
    letter.
12. **Date and time — keep as a low-complexity scanning item.** Copying an
    appointment accurately is a legitimate Pre-A1 reading ability. The
    alternatives change the day or time.
13. **Colors and adjectives — keep.** `It isn't large` requires the student to
    interpret the description rather than copy the word `small`.
14. **Family members — keep as direct vocabulary evidence.** The language is
    deliberately simple, but the student must change `my sister` to
    `Omar's sister`.
15. **Classroom objects — keep.** The student chooses objects that satisfy a
    teacher instruction instead of matching a repeated object word.
16. **Countries and nationalities — keep.** This directly tests the taught
    transformation from country to nationality.
17. **Number listening — keep.** `$40` versus `$14` tests the important
    `-ty` / `-teen` contrast without adding arithmetic.
18. **Build an introduction — keep.** The alternatives represent a viewpoint
    error and a missing `from`, while all the supplied personal details remain
    easy to inspect.
19. **Complete a form — keep.** The student must map information to three
    functional fields. No answer is revealed by repeating an obvious field
    label alone.
20. **Choose a personal question — keep.** All three choices are correct
    English questions, so the student must choose the function required by the
    situation.

## Teacher Evidence

- **Speaking task — keep, teacher-scored.** Four separate points cover greeting
  and introduction, asking, answering, and spelling. The student should not
  read complete prepared sentences.
- **Writing task — keep, teacher-scored.** Two points require actual production:
  completing a mini form and writing two short personal sentences. Multiple
  choice is therefore no longer mislabeled as writing.

## Score Profile

- Grammar: 7 points
- Reading: 2 points
- Vocabulary: 6 points
- Listening: 2 points
- Functional language: 3 points
- Speaking: 4 points
- Writing: 2 points
