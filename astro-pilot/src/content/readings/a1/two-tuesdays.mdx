languageFocus:
  title: Routine or temporary situation?
  explanation: Present simple describes Nina’s normal Tuesday. Present continuous describes the changed situation happening this Tuesday and around now.
  examples:
    - { text: "I normally work at the north office.", note: "Normally marks a repeated routine, so the message uses present simple." }
    - { text: "This Tuesday, I’m working downtown.", note: "This Tuesday marks a temporary change, so the message uses present continuous." }
    - { text: "I finish at three.", note: "Her usual ending time remains part of the routine." }
    - { text: "Marta is seeing her doctor.", note: "The appointment is arranged for today, not a permanent routine." }

craft:
  title: How a short message prevents confusion
  introduction: Nina separates the normal routine from the temporary change and ends with one clear request, so Luis knows what is different and what action to take.
  moves:
    - label: Time contrast
      example: "Normally... This Tuesday..."
      effect: Two time markers let the reader compare the routine and today’s exception immediately.
    - label: Direct request
      example: "Could you send me the client notes before lunch?"
      effect: The final question turns background information into one specific next action.

  - name: Main points
    prompt: What is normal, and what is different today?
    chunks: [She normally..., Today, she is..., One thing is still the same...]
