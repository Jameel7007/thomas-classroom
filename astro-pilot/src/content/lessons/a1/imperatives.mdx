## Get to the root: the listener is understood

An imperative begins with the base verb because the subject **you** is normally understood from the situation. The speaker directs the words toward the listener: *(You) open the file.* English leaves *you* unspoken because it is already obvious.

The grammar is compact, but the social meaning depends on context. *Turn left* can be helpful directions. *Take one tablet with food* can be medical instructions. *Don’t move* can be an urgent warning.

| Purpose | Pattern | Example |
| --- | --- | --- |
| Positive instruction | base verb | Save the document. |
| Negative instruction | don’t + base verb | Don’t delete the original. |
| Polite direct request | please + imperative | Please send me the address. |
| Shared suggestion | let’s + base verb | Let’s check it together. |

## Tone changes the relationship

A bare imperative can be neutral, friendly, urgent, or rude. Instructions on a screen are neutral. The same form spoken to a coworker may need *please* or a request with *Can you…?*

| Form | Typical effect |
| --- | --- |
| Send me the address. | clear and direct |
| Please send me the address. | polite, but still direct |
| Can you send me the address? | framed as a request |
| Let’s check the address. | includes speaker and listener |
