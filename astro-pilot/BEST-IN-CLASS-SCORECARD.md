# Best-in-Class ESL Product Scorecard

**Audit date:** July 16, 2026
**Scale:** 1 = materially absent or unreliable; 2 = limited; 3 = credible; 4 = strong; 5 = category-leading in the audited set.

Scores evaluate the public product a tutor or adult learner can actually use, not company size or marketing claims. A score of 5 does not mean flawless. Competitor accessibility and technical scores are conservative public-product judgments, not formal WCAG conformance or laboratory performance results.

## Score definitions

| Score | Standard |
| --- | --- |
| 1 | The capability is missing, incidental, or works against the intended use. |
| 2 | Some evidence exists, but coverage, quality, or workflow is materially limited. |
| 3 | A dependable baseline exists with meaningful gaps. |
| 4 | Strong, consistent implementation that supports the main users well. |
| 5 | A leading implementation with breadth, depth, and a mature supporting workflow. |

## Areas

| Code | Product area | What earns a high score |
| --- | --- | --- |
| A | Curriculum coherence | Explicit sequence, outcomes, levels, prerequisites, and assessment alignment |
| B | Pedagogical accuracy | Edited, natural, level-appropriate language with documented review |
| C | Lesson thoroughness | Sufficient explanation, examples, practice, production, and review |
| D | Exercise clarity and context | One defensible answer, useful context, plausible distractors, explanatory feedback |
| E | Multiple teaching approaches | Meaningfully different routes into a concept, not only different task widgets |
| F | Speaking and fluency development | Structured rehearsal through sustained, purposeful production |
| G | Pronunciation and connected speech | Sound, stress, rhythm, reductions, linking, and intonation tied to language use |
| H | Listening quality | Clear, varied, level-appropriate recordings and meaningful listening tasks |
| I | Assessment quality | Valid diagnostic/progress evidence across receptive and productive skills |
| J | Teacher preparation time | A tutor can find, understand, adapt, and teach the material quickly |
| K | Student independence | Clear directions, media, feedback, and review without constant teacher mediation |
| L | Search and discovery | Fast, relevant filtering by level, topic, skill, format, and availability |
| M | Interactivity | Useful browser-native or digital interaction that supports learning |
| N | Progress and personalization | Assignments, retrieval, history, recommendations, and actionable reports |
| O | Printable and homework support | Teacher/student versions, notes, keys, printable work, homework, and review |
| P | Accessibility and mobile usability | Keyboard, screen reader, contrast, responsive layout, calm small-screen use |
| Q | Visual quality | Readable, coherent, adult-appropriate design that supports instruction |
| R | Technical reliability | Stable delivery, low-friction access, dependable media and workflows |
| S | SEO and public discoverability | Crawlable public catalog, useful metadata, content authority, and indexable routes |
| T | Commercial value | Useful free access or a clear paid offer with strong capability-to-price value |

**Interpretation:** Thomas’s Classroom is already competitive in coherence, thoroughness, speaking, spoken-form instruction, direct discovery, browser interactivity, visual quality, and static reliability. Its score is held down by exactly the areas the audit recommends addressing first: review evidence, exercise feedback, method diversity, real listening, homework/retrieval, and progress continuity.
